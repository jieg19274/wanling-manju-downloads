# 万灵漫剧 · Windows 下载

万灵漫剧是本机 AI 漫剧制作软件，支持原文分集、正式剧本、人物及场景素材、分镜、画布制作、模型生成、审片、MP4 合成及剪映草稿导出。数据保存在使用者本机，模型密钥由使用者自行配置。

**[下载 0.4.24 Windows x64 本地试用包](https://github.com/jieg19274/wanling-manju-downloads/releases/tag/v0.4.24-trial.1)** · [安装说明](docs/INSTALL.md)

## 安装

1. 安装 Windows x64 Node.js 24。
2. 从 Releases 下载 ZIP，解压到自己的可写文件夹。
3. 双击“准备试用环境.cmd”，从官方 npm 安装锁定的运行依赖。
4. 双击“启动试用.cmd”，按包内“新手制作全流程.md”操作。
5. 制作和导出新视频需要另外安装 FFmpeg/FFprobe；具体方法见安装说明。

公开演示项目和样片可离线观看，无需密钥。制作新内容时需在设置中填写自己的模型密钥，真实生成按供应商实际用量计费。本包没有附带 Node、FFmpeg、sharp/libvips、Real-ESRGAN 可执行运行库或模型。
